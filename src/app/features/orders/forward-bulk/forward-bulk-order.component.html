Bulk Upload Instructions

  1. Add a warehouse by entering the pickup details to generate a warehouse ID.
  2. Fields marked with a star (*) are mandatory, while fields without a star are optional.
  3. Fill in all the relevant fields in the appropriate format and upload the file in CSV format.

Note

  1. Pickup Address Id is a numeric value that serves as the digital identifier for your or your vendor's pickup address.
  2. COD Amount value refers to the amount to be collected from the consignee at the time of delivery. If the input value is "0", the payment mode is considered to be prepaid and no amount will be collected from the consignee.
  3. Insurance secures your high-value invoice shipments against loss and damage. Go to settings to automatically secure all shipments and input "Y" under the column "Insurance (Y/N)" to secure a shipment.
  4. Product Value refers to the declared amount of the shipment. If the input amount is more than Rs 50,000, then uploading an Ewaybill number is mandatory.
